# 光影实验室 · Light Studio

基于 **Three.js**（v0.160，本地依赖，无需联网）的 3D 光影演示与调节工具。可自由选择展示
立方体、球体、圆柱、圆锥、四面体、八面体、二十面体、十二面体、圆环结等标准 3D 模型，
并实时调节光照环境。

## ✨ 功能特性

### 模型（左侧面板）
- 9 种标准模型：立方体 / 球体 / 圆柱 / 圆锥 / 四面体 / 八面体 / 二十面体 / 十二面体 / 圆环结
- **自由选择展示哪些模型、展示几个**：点亮按钮即可增减，多模型按占地宽度自动排开居中；
  点击 3D 场景中的模型选中编辑（地面金色圆环指示，不随模型旋转、不闪烁）
- **朝向调整**：绕 X / Y / Z 轴任意旋转（0–360°），一键重置朝向（多面体默认一个平面贴地，
  旋转后模型自动贴地）
- **「吸附面朝地」**：开启后点击模型表面，该面将转至水平并**朝向地面**（模型骑坐在该面上）
- **所有参数均可直接输入数值**（滑杆与数字输入框双向同步）；可一键「重置模型参数」（保留朝向）
- 其他可调参数：颜色、金属度、粗糙度、X/Y/Z 三轴缩放比例、球面/径向/管状细分段数、
  圆柱顶面半径比（0=圆锥，1=正圆柱）、多面体细节层级、**边线显示**（在实体表面叠加边缘线，
  颜色随模型颜色自动加深，方便观察边的光影）、线框显示、自转速度（默认不旋转）

### 光照（右侧面板）
- **光源数量**：1–6 个可独立配置的光源
- 每个光源支持：
  - 类型切换：平行光 / 点光源 / 聚光灯
    （点光源 = 四周发散的圆形光斑；聚光灯 = 定向锥形光束，**锥角/羽化**控制光束集中度与边缘软硬，
    地面受光后两者的光斑形状差异一目了然）
  - **色温**（1000K–12000K，开尔文 → RGB 实时换算）或自定义颜色
  - **强度**、**方位角**、**仰角**、**距离**，
    所有参数滑杆与数值输入框双向同步，可直接输入精确值
  - 启用开关、投射阴影开关
- 全局：环境光强度/色温、半球光、ACES 色调映射曝光度、4 种背景
  （地面随背景自动配色并**接收光照**，点/聚光的光斑、阴影都直接可见）
- 场景中的光源标记（光球、方向箭头、锥形光束线）实时随参数移动，可一键隐藏
- 6 套灯光预设：影棚标准 / 正午日光 / 日出黄昏 / 清冷月光 / 舞台霓虹 / 影棚柔光

### 其他
- 轨道相机：拖拽旋转、滚轮缩放、右键平移
- **视角控制坞（画面中间底部，三栏并排）**：左「预设视角」6 个默认视角一键切换；
  中「视角参数」方位角/仰角/距离滑杆与数值输入双向同步、鼠标拖动实时跟随；
  右「自定义视角」保存/应用/内联重命名/删除，持久保存
- **保存截图带参数**：截图左上角叠加视角/光照/模型/背景等参数信息，
  文件名同时携带这些参数（如 `light-studio_AZ45_EL30_D12.0_L2_暗色影棚_时间.png`）
- **「保存为默认配置」**：一键把当前全部设置存为默认配置，下次启动自动加载；
  「重置全部设置」恢复为已保存的默认（未保存过则恢复出厂预设）
- 自动旋转、参考网格、全屏、FPS 显示
- 设置自动保存到浏览器 localStorage（刷新/重启浏览器不丢失）

## 🚀 运行方式

> 页面使用 ES Module，直接双击 `index.html`（file:// 协议）无法运行，需通过本地服务器访问。

**方式一（推荐）**：双击 `光影工作室.bat` —— 自动挑选空闲端口，
**先立即用系统默认浏览器打开页面（`start` 命令），随后再启动服务器**
（浏览器启动耗时正好覆盖服务器启动，页面加载时服务已就绪）。
（服务器依次尝试 Node.js → Python → npx）

**方式二**：手动启动，任选其一：

```bash
node serve.js          # 自动选择空闲端口，监听成功后自动打开浏览器（多重策略兜底）
# 或
python -m http.server 8321 --bind 127.0.0.1
# 或
npx http-server -p 8321
```

然后访问控制台打印的地址（默认 **http://127.0.0.1:8321/** ）。
> 若不希望自动打开浏览器（Node 方式），设置环境变量 `OPEN_BROWSER=0` 即可。

## 🛠 技术说明

- 渲染：WebGL + Three.js r160，ACES Filmic 色调映射，PCF 软阴影
- 光照模型：经典强度标定（0–10 直观量级），点/聚光灯带 25m 截止距离与平方衰减，
  三种光源类型亮度表现一致、兼容性最佳
- 色温换算：Tanner Helland 近似算法（1000K 烛光 → 12000K 蓝天）
- 无构建步骤、无外部 CDN，开箱即用
